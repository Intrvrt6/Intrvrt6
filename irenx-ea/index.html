Core Intelligence

Setiap layer punya fungsi. Forecast memperkuat thesis — bukan menggantikannya.

00 / Data Quality

Validasi spread, candle anomaly, liquidity, data integrity dan extreme volatility sebelum signal.

01 / Regime

Trend, range, accumulation, distribution, expansion, compression dan transition.

02 / Liquidity

Identifikasi buy-side/sell-side liquidity, sweep, equal highs/lows dan liquidity void.

03 / Reflexivity

Membaca sweep → rejection → displacement → follow-through untuk memvalidasi reaksi market.

04 / Orochi

BOS, CHOCH, MSS, displacement, imbalance dan struktur multi-timeframe.

05 / VMAP

Confirmation lintas timeframe: price position, slope, alignment dan distance.

06 / Forecast

Forecast path, expected return dan volatility sebagai predictive evidence tambahan; tidak pernah menjadi trigger tunggal.

07 / Temporal Context

Session dan multi-timeframe context membantu membedakan setup yang sama pada kondisi waktu berbeda.
